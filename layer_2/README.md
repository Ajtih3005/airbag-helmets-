# Layer 2 — 3D Visual Simulation & Real-Time Telemetry Interface

## Overview
Layer 2 is responsible for:
1. **Sensor-Driven 3D Animation:** Driving the 3D motorcycle and rider helmet visuals using the 9-channel sensor data generated by Layer 1 (`ax, ay, az, gx, gy, gz, hg_ax, hg_ay, hg_az`).
2. **Interactive Controls:** Providing UI controls for scenario triggering, HUD telemetry gauges (speed, lean angle, gravity loss, high-G impact), and real-time graph plotting.
3. **Live Streaming Server:** Streaming telemetry frames to the visualizer and relaying data to the ML engine (Layer 3).
